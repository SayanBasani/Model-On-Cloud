AI Model API

Run AI through a simple API

Model On Cloud provides a simple HTTP API for sending prompts to an AI model and receiving generated responses.

View API How to use

What is Model On Cloud?

A lightweight HTTP interface around an AI model. Your application sends a request and receives a JSON response.

Simple API

Send a POST request with your message and receive the generated response.

JSON

Requests and responses use JSON, making the API easy to integrate.

Any Client

Use the API from JavaScript, Python, mobile applications, or any HTTP client.

API Endpoint

Send your AI request to this endpoint.

POST /api/chat 
POST /api/chat
Content-Type: application/json

{
    "message": "Explain artificial intelligence"
}

Request Parameters

Parameters currently accepted by the API.

Parameter Type Required Description
message string Yes The question or prompt sent to the model.

How to use

Example JavaScript request. 

const response = await fetch(
    "https://your-domain.vercel.app/api/chat",
    {
        method: "POST",

        headers: {
            "Content-Type": "application/json"
        },

        body: JSON.stringify({
            message: "What is machine learning?"
        })
    }
);

const data = await response.json();

console.log(data.answer);

Example response: 

{
    "success": true,
    "answer": "Machine learning is a branch of AI..."
}
